Installation

Start in four simple steps.

  1. 1

    Open the Chrome Web Store

    Open the Lightning Craft listing in Chrome.

  2. 2

    Add Lightning Craft to Chrome

    Select Add to Chrome, then confirm with Add extension.

  3. 3

    Sign in to Salesforce

    Open a supported Salesforce domain in Chrome and sign in with the account and org you intend to work with.

  4. 4

    Open the launcher

    Use the Lightning Craft drawer on a Salesforce page, then choose Data Export, Data Import, Metadata Export, Metadata Import, REST Explorer, or Developer Console.

Troubleshooting

Common questions

Why does Lightning Craft say there is no Salesforce session?

Sign in to Salesforce in the same Chrome profile, then return to a supported Salesforce page. The extension uses the active Salesforce session; it does not accept a separate Salesforce password or API token.

Why cannot I query an object or update a field?

Lightning Craft respects the Salesforce org, user permissions, object permissions, field-level security, session state, and API limits available to the signed-in user. Confirm access in Salesforce and try again.

Where are saved mappings, query history, and package configurations stored?

These workspace items are stored locally in your browser using extension storage. They are not saved as Salesforce records by the extension.

How should I use Metadata Import safely?

Inspect package contents, review deployment options, validate before deploying where appropriate, and follow your organization's change-management process. Testing in a non-production org is recommended.

Are Local Files automatically uploaded to Salesforce?

No. Local Files are optional scratch files held in the extension cache. They are not synchronized unless you deliberately import, export, or deploy them.

Still need help?

Share enough context for a useful answer.
