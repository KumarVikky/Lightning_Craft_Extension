Privacy policy

Your Salesforce work stays
under your control.

Lightning Craft works with the Salesforce session already active in your browser.
It does not require a separate Salesforce password or API token.

Overview

Designed for your active Salesforce context.

Uses your active session

Salesforce requests use the signed-in browser session for the org you are working in.

Local workspace storage

Preferences, saved work, backups, and tool history stay in your browser unless you explicitly send a request.

No advertising or sale

Lightning Craft does not sell Salesforce data or use it for advertising or behavioral profiling.

Information handled

What the extension can access.

The extension handles only the information needed to provide the feature you initiate, including:

  • Your Salesforce session cookie (sid) so requests can be authenticated with the org already open in your browser.
  • Salesforce data and metadata returned for actions you request: object and field definitions, records, SOQL results, deployment details, source files, REST responses, and debug logs.
  • Content you explicitly provide, such as CSV, Excel, ZIP packages, pasted records, JSON, Apex/SOQL, debug logs, and metadata selections.
  • Saved REST request details, such as endpoint, method, parameters, non-sensitive headers, and request body. Authorization, Proxy-Authorization, X-API-Key, and Cookie headers are excluded from saved request shapes.
  • Workspace preferences and locally saved tool state, such as recent queries, mappings, editor settings, and selected UI options.

How it is used

Requests go where you direct them.

Salesforce data is sent to your connected Salesforce org only when you use an extension feature that makes that request. REST Explorer can also call an external HTTPS endpoint only after you enter or select that endpoint and approve the optional site permission. Plain HTTP endpoints are rejected.

The extension does not run a general remote proxy for your Salesforce data, and it does not use your content for advertising, profiling, or sale.

Local storage

Workspace data is stored in your browser.

Lightning Craft uses Chrome local extension storage, browser local/session storage, and IndexedDB to preserve the workspace features you choose to use. This can include saved queries, import mappings, request shapes, editor preferences, local files, debug analyzer workspaces, and raw debug-log text.

Metadata Import may keep a local IndexedDB backup of a ZIP deployment snapshot so you can restore it during the import workflow. Those backups are pruned after 24 hours, and obsolete backups are removed.

Storage is scoped to your browser profile and is not automatically synchronized by Lightning Craft to an external Lightning Craft service. You can remove saved items through the relevant workspace controls or clear the extension's site/extension data in Chrome.

Uninstall feedback

Feedback is optional.

When Lightning Craft is uninstalled, Chrome opens a Google Form where you may optionally provide feedback. The extension does not automatically send Salesforce data, extension storage, or other personal information to that form. Any information you choose to submit is provided to Google through the form and is subject to Google's applicable policies.

Your choices

You control each action.

  • Use only the Salesforce features and external endpoints you choose.
  • Review and remove saved queries, mappings, request shapes, files, and backups from the relevant tools.
  • Clear Lightning Craft storage from Chrome's extension/site data controls.
  • Contact the project maintainer through the documentation repository for privacy questions or corrections.
