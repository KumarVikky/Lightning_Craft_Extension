Information handled

Information used to provide the extension

Lightning Craft handles only the information required for a workflow you initiate:

  • Salesforce session information. The extension reads the Salesforce sid cookie from supported Salesforce domains to make authorized requests with the current signed-in session.
  • Salesforce content you choose to work with. This can include metadata, records, query results, metadata components, source files, API responses, and operation results.
  • Files and text you supply. CSV, XLS, XLSX, ZIP, pasted data, code, and clipboard content are handled when you deliberately use the related import, metadata, copy, paste, or Local Files workflow.
  • REST Explorer request information. When you select an external HTTPS target, the request details and data you provide are sent to that selected endpoint only.
  • Workspace preferences. This includes UI settings, query history, mappings, saved request shapes, saved package configurations, and Local Files.

Purpose limitation

How information is used

Information is used only to perform the feature you initiate: displaying Salesforce context, querying data, preparing an import, retrieving or deploying metadata, working with source files, calling a REST endpoint, exporting results, or saving local workspace preferences.

Lightning Craft does not use Salesforce information for behavioral advertising and does not sell it. Salesforce data is sent to the connected organization as required by your requested workflow. External HTTPS data is sent only to an endpoint you explicitly select in REST Explorer.

Browser-local data

Local storage and retention

Saved preferences and workspace items are stored with chrome.storage.local in the browser profile where the extension is installed. Local Files are scratch files in the extension cache and are not automatically synchronized with Salesforce.

You can remove browser-local extension data by clearing the extension's stored data or removing the extension. Deleting a saved configuration or Local File removes that local item from extension storage.

Your choices

You decide what is processed

Use only the workflows and actions you intend to use. Review staged data, selected metadata, generated packages, deployment settings, and CRUD operations before proceeding. Salesforce permissions, field-level security, API limits, and session state can limit access.

For sensitive or production data, follow your organization's Salesforce policies and use appropriate care when exporting, copying, importing, deploying, or calling external endpoints.
