Explore the workspace

One launch point.
Everyday Salesforce work, connected.

Lightning Craft brings data, metadata, deployment, REST, and developer workflows into the Salesforce context you already use.

01 · Launcher and drawer

Start from the page you are already on.

The in-page drawer keeps searchable objects, users, organization context, record actions, and workspace entry points within the current Salesforce session.

  • Open direct workspace actions from Salesforce
  • Browse object, user, and organization context
  • Use record-level actions without leaving the page
  • See recent deployment activity for this org

02 · Data View

Understand a record in its full Salesforce context.

The launcher detects the record and object open in Salesforce, then presents its available data and metadata together in a focused Data View workspace.

  • Detect the current Salesforce object and record from the page
  • Review record values alongside field metadata
  • Clone an existing record when a similar record is needed
  • Modify eligible values directly from the workspace

03 · Data Export

Move from object discovery to usable data.

Browse objects and fields, construct SOQL in a dedicated editor, inspect results, and export or copy the data you need.

  • Object explorer and searchable fields
  • Parent and child relationship suggestions
  • Cursor-aware field insertion and subquery support
  • Tooling API queries, templates, validation, and results actions

03 · Data Import

Prepare changes before they reach your org.

Stage CSV, Excel, pasted, or manually entered records. Map fields, validate rows, review operations, then apply the permitted change with a clear result trail.

  • Create, update, upsert, or delete where access permits
  • Column mapping, validation, and editable staged rows
  • Review saved mappings and select Update Mapping when a change is needed
  • Clear per-row outcomes after processing

04 · Metadata Export

Build focused retrieval packages.

Discover metadata types and components, assemble a precise selection, inspect relationships, generate package.xml, and download a Metadata API ZIP package.

  • Searchable metadata discovery and component selection
  • Generated package.xml with saved local configurations
  • Dependency review for selected components
  • Readable retrieval activity and downloadable ZIP output

05 · Metadata Import

Validate and deploy packages with intent.

Upload a Metadata API ZIP, inspect its contents, set deployment options, validate first, and deploy when ready. Deployment logs keep the work visible from start to finish.

  • Package ZIP staging and content inspection
  • Validation and deploy actions with deployment options
  • Quick Deploy for eligible validations
  • Deployment activity, status, and local recovery support

07 · Deployment View

View metadata deployment details directly from the launcher.

Open Deployment View to review this org's metadata deployment activity, component outcomes, tests, timing, and errors without leaving your Salesforce context.

  • Recent deployment activity and searchable history
  • Validate, Deploy, and In Progress status clarity
  • Component-level errors and deployment details
  • Test counts and completion timing

07 · Developer Console

Keep source, comparisons, and developer tasks in one view.

Browse supported Salesforce source in a Monaco-based editor, compare changes, use scratch files, run common developer workflows, and turn JSON into a copy-ready Apex wrapper.

⌘

Explore and edit

Browse supported Salesforce source and work with Apex, Aura, Lightning Web Components, Visualforce, and more.

⇄

Compare with context

Review a file against its org version or compare two files side by side before proceeding.

JSON and SOQL tools

Inspect JSON as an interactive tree, generate Apex wrappers, execute SOQL, and copy result data as JSON.

08 · REST Explorer

Explore APIs with ease.

Call Salesforce REST resources or approved external HTTPS endpoints from an organized request builder. Inspect a formatted response and keep a useful activity trail nearby.

  • Salesforce REST and external HTTPS request targets
  • Configurable methods, paths, parameters, headers, and JSON bodies
  • Formatted response viewer with copy and download actions
  • Saved request shapes and request activity history
