Latest release · v1.3

More control in every Salesforce workflow.

Version 1.3 refines the everyday workspace with more focused layouts, scalable deployment review, useful organization context, and safer debug-log controls.

01

Organization insights from Salesforce Trust

The Organization drawer now surfaces the nearest Salesforce release and maintenance information for the active instance. Each value opens the matching Salesforce Trust page in a new tab.

02

Safer Apex debug-log cleanup

Delete logs for the selected user from the Users tab, or clear all org debug logs from Organization. Both actions require a clear in-drawer confirmation before anything is removed.

03

A sharper REST Explorer

Method, full request URL, and request actions now sit together in one compact request bar. The activity log and saved-request workspace are cleaner, more compact, and easier to scan.

04

Clearer metadata workflows

Metadata Import and Metadata Export use compact headers, consistent step labels, refined activity areas, and more focused package and deployment surfaces.

05

Deployment review that scales

Component errors, successful components, and test failures now have fixed-height, resizable tables with wrapped detail, internal scrolling, automatic progressive loading, and individual Copy CSV actions.

06

Focused data workspaces

Data Export, Data Import, and Data View receive tighter edge-to-edge layouts. Data Export also adds an Object Explorer hint to help move from object selection to query building faster.

Previous release · v1.2

A broader Salesforce workspace.

Version 1.2 adds metadata deployment, REST exploration, richer query building, deployment clarity, and new developer tools while refining the workflows already in use.

01

Metadata Import and deployment controls

Stage Metadata API ZIP packages, review package contents, choose deployment options, validate first, deploy to Salesforce, and use Quick Deploy when a validation is eligible.

02

Clear deployment history

Deployment views show this org’s recent activity, component outcomes, test results, errors, and whether a request is validating, deploying, or still in progress.

03

Relationship-aware Data Export

Build SOQL with parent and child relationship suggestions, subquery support, cursor-aware field insertion, a resizable relationship browser, Tooling API queries, and up to 12 field chips.

04

Richer metadata retrieval

Metadata Export gains clearer retrieval activity, dependency views, generated package.xml, and polished retrieval logs.

05

REST Explorer

Call Salesforce REST resources or approved external HTTPS endpoints, configure parameters, headers, and JSON bodies, inspect formatted responses, and copy or download results.

06

Developer Console additions

Use a JSON parser with an interactive tree and Apex wrapper generation, copy SOQL result JSON, and access an expanded set of Console workflows.

07

Data Import mapping refinement

Review an existing mapping without disruption, then choose Update Mapping to expose every mapped column and replace its Salesforce field deliberately.

08

Focused UI fixes

Improved text sizing, matching controls, responsive panels, loading copy, and clearer status language make the workspace easier to scan.

09

Expanded Developer Console toolkit

Developer Console now includes Command Palette access to SFDX-style actions, Execute Anonymous Apex, Execute SOQL Query with relationship-aware JSON copy, Log Analyzer, Run Test Class, JSON Parser, and deliberate browser-local Local Files support alongside source editing and comparisons.

10

Data View from the launcher

Open Data View directly from the active Salesforce record context to inspect record values alongside field metadata, then clone an existing record or update eligible values without losing the surrounding Salesforce context.

Previous release · v1.1

More polished, more consistent.

Lightning Craft v1.1 refines the workspace and the tools you use every day, with improvements to component creation, editing, navigation, and Salesforce access.

01

Choose the right Salesforce API version

Developer Console creation dialogs load the available API versions from the connected Salesforce org. The version you choose is used when creating or deploying supported components.

02

Clearer editing for Local Files

Local Files use their file type to select the editor language, bringing syntax colors to supported files while you work on scratch content.

03

Keyboard-friendly dialogs

Move between modal action buttons with the left and right arrow keys in Developer Console, Settings, data tools, metadata dialogs, and drawer confirmations.

04

Focused Salesforce access

Salesforce origin checks were strengthened and extension permissions were streamlined for the supported Salesforce workflows.

05

A more consistent Lightning Craft experience

Branding and small interface details were refined across the launcher, Developer Console, and supporting pages.

Initial release · v1.0

A connected toolkit for Salesforce teams.

Version 1.0 is designed to reduce context switching while keeping important actions visible, reviewable, and grounded in your active Salesforce session.

01

Salesforce-native launcher

Open the extension directly from supported Salesforce pages and keep your current org context in view.

02

Data Export

Browse objects and fields, build SOQL queries, inspect results, and export or copy data in practical formats.

03

Data Import

Stage CSV, Excel, pasted, or manually entered records, map fields, validate rows, and review operations before execution.

04

Data View

Inspect records and field details with a focused view for understanding Salesforce data in context.

05

Metadata Export

Discover metadata types, select components, review dependencies, generate package.xml, and export Metadata API ZIP packages.

06

Developer Console

Browse supported source, edit files, compare changes, work with local scratch files, and run developer workflows.

07

Local-first preferences

Keep settings, query history, mappings, package configurations, and Local Files in the browser profile where you use the extension.

08

Review-oriented workflows

Use validation, staging, selection, and result views to make informed changes in the connected org.

09

Built-in documentation and support

Find product guidance, privacy details, troubleshooting help, and a direct path to report bugs.
